## DDD implementation record

- Bounded contexts: Identity issuer and Edge authentication.
- Use case: build resource-server configuration after Nest configuration loading.
- Aggregate: none; this is composition-time configuration.
- Invariants: Identity and Gateway use the same HTTP issuer default; explicit
  configuration wins; malformed URLs fail closed.
- Consistency boundary: one Nest application bootstrap.
- Affected ports: none.
