# MCP Inspector evidence

This directory contains redacted Inspector evidence. The automated protocol
proof is linked from the [Milestone 7 evidence index](../milestone-7/README.md),
and the CLI Inspector execution is recorded in the
[Inspector summary](inspector-summary.md).

Before adding an artifact, verify that it contains no bearer token,
`Authorization` header, client secret, token payload, or copied request export.
Screenshots are supplementary only; CI runs the MCP protocol acceptance target
as the authoritative proof.
