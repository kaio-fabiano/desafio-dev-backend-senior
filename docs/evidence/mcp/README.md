# MCP Inspector evidence

This directory is reserved for manually captured, redacted follow-up evidence. The automated protocol proof is linked from the [Milestone 7 evidence index](../milestone-7/README.md).

Before adding an artifact, verify that it contains no bearer token, `Authorization` header, client secret, token payload, or copied request export. Prefer a short Markdown summary with the date, environment, listed tool names, and invoked tool names. Screenshots are supplementary only; CI runs the MCP protocol acceptance target as the authoritative proof.
