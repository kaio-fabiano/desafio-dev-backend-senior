## Reading rule

- **Required** restates a challenge requirement.
- **Proposal** is a recommended technical decision that is still reversible.
- **Question** requires validation or a proof of concept.
- **Differentiator** adds evaluation value but does not block the minimum delivery.

## Deliverables that must not disappear from the plan

- Nx monorepo using project graph, pipelines, cache, generators, and `nx affected`.
- Complete environment via Docker Compose, with healthchecks.
- Composed and versioned supergraph as a build artifact.
- Seed scripts for OAuth2, users, suppliers, and products.
- Executable collection of GraphQL operations.
- Single E2E test from scratch, including MCP and the payment processor.
- MCP Inspector evidence.
- SST infrastructure and CI/CD pipeline.

## Global definition of done

The project is ready only when the workflow in section 15 of the README passes
from scratch, authorization rejections pass, federated composition passes,
coverage of critical domains is at least 70%, concurrent idempotency is proven,
and the documentation explains the decisions left open by the challenge.
